# Portfolia

A React + Vite portfolio builder. Deploys on Vercel.
## Deploy
Import the project into Vercel. Build command: `npm run build`. Output folder: `dist`.

## Admin
Open `/admin` for the separate admin interface. It intentionally shows empty states until your backend is connected. Before launch, protect `/admin` and every admin API with server-verified authentication and role checks.

## Backend later
Sign-in, live AI, saved data, payments and publishing still need backend integration.
